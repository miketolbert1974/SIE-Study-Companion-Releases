# SIE Study Companion — downloads

[Download the Mac + Windows pilot](https://github.com/miketolbert1974/SIE-Study-Companion-Releases/releases)

One ZIP. Extract it, open START-HERE.html, choose your computer. Use **Mac/Start Companion.app** or **Windows/Start Companion.cmd**. Google Chrome only. First install uses **Load unpacked**, not Pack extension; follow the guided setup and pin the toolbar icon. No copying files, Node install, typed commands or API key.

**Live AI needs your own ChatGPT Plus (Pro also supported)** and available Luna access/usage. Free/Go do not support this connection. Offline practice, saved notes and recall need no subscription; mock replies are not verified answers. No shared account or separate API billing.

## Updates: keep your existing extension

1. Companion **Settings → Check for updates** (or use the downloads link above).
2. Download and extract the new ZIP; open your computer's new **Start Companion**.
3. **Settings → Reload companion**, then reopen its pinned icon. Alternatively reload its card at chrome://extensions.

Do not remove the extension or use Load unpacked again. Save drafts and export all data for backup first. Notes, progress and connection stay in place. Use the new starter from then on. Helpers before 0.7.6 need one computer restart for their first upgrade. Very old Downloads-based installations need a one-time stable-folder migration. Revoked/expired sessions may require sign-in again. No silent downloads or execution.

## Know before sharing

This is a **peer-test pilot**, not a fully verified release. Mac requires macOS 13.5+ (Apple Silicon or Intel); Windows targets Windows 11 x64/ARM64. Real Windows launch, private permissions, own-account Luna and restart checks are pending. The free Mac starter is not Apple-notarized; the Windows starter is not a signed installer. Personally review any OS warning; never disable security or bypass school IT policy. Stop on malware/damaged-app messages or an unexpected Rosetta request.

Help and troubleshooting are included as START-HERE.html and inside the companion. Report version, OS/CPU, setup step, exact error and a cropped screenshot. Never send passwords, codes, full sign-in URLs, session files or private logs. This independent aid is not affiliated with Achievable, FINRA or OpenAI and cannot guarantee an exam pass. It never selects or submits an Achievable answer.

This repository hosts application releases and instructions only. Student data and accounts are never included. Third-party source/license notices are inside the download. Choose the named companion ZIP under Assets, not GitHub's automatically generated Source code archives.
